📅 Elite Events Management Website
Project Overview
This is a multi-page static website for an Event Management Company called "Elite Events" (inferred from project.html). It is designed to showcase the company's services, capture client bookings, and display client testimonials.

The site is built using HTML and CSS (primarily inlined or within <style> tags) and includes basic JavaScript for form validation and user feedback.

🛠️ Technology Stack
HTML5: For the page structure and content.

CSS3: For styling and layout.
JavaScript: For client-side form validation on the login and booking pages.

📁 File Structure
The project is composed of five main HTML files and associated assets (images linked externally).
File Name,Description
index.html,Login Page: The initial entry point with email and password validation.
index2.html,Home Page: The main landing page with a brief company description and navigation.
events.html,"Events Page: Lists and describes the main event categories (Wedding, Corporate, Birthday, Custom)."
project.html,Details/Booking Page: Contains the booking form and information on the booking process.
testimonials.html,Testimonials Page: Displays client feedback and reviews.
✨ Key Features
Multi-Page Navigation: Clear navigation links across all primary pages (index2.html, events.html, project.html, testimonials.html).

Login Functionality: A basic front-end login page (index.html) with JavaScript validation for email format and password length (minimum 6 characters). Successful login redirects to the Home page (index2.html).

Event Categories: Dedicated page (events.html) showcasing four main service types: Wedding, Corporate, Birthday, and Custom Celebrations.

Booking Form: A detailed booking request form (project.html) that captures the client's name, email, event type, date, guest count, and notes.

Form Submission Feedback: The booking form uses a simple JavaScript alert to confirm submission and clear the form.

Client Testimonials: A page (testimonials.html) dedicated to showcasing client reviews.

Responsive Design: Basic use of standard CSS for decent viewing experience (though further optimization is recommended).

📝 Usage
Login: Enter an email (must be a valid format) and a password (must be 6+ characters) on index.html.

Navigate: Use the header navigation bar to explore the different pages.

Book an Event: Go to the "Details" (project.html) page, fill out the form, and click "Send request".

View Services: Check the "Events" page (events.html) to see the service categories.
